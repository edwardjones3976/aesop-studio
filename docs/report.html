Independent review

Reviewer: an independent subordinate session that wrote no code and had read-only access. It found 10 issues. Disposition:

  • Fixed: cross-project preview read (+test)
  • Fixed: SSRF via DNS rebinding and CGNAT (pinned vetted IP; is_global) (+test)
  • Fixed: redaction gaps for Bearer, JSON password, Google keys and PEM (+test)
  • Fixed: stuck-pipe task. The reader is joined with a timeout, and an orphaned descendant now gives EFFECT_UNKNOWN instead of hanging RUNNING
  • Fixed: non-atomic one-writer check (now inside BEGIN IMMEDIATE)
  • Fixed: extra billing env vars (CODEX_API_KEY, ANTHROPIC_AUTH_TOKEN, Bedrock/Vertex, base URLs) are stripped, and the route is held if present
  • Fixed: Windows zip-slip on restore
  • Fixed: negative Content-Length
  • Documented, not fully fixed: Codex chat -s read-only can still read files outside the working folder, and Codex's workspace-write enforcement on Windows is not independently verified. Use Claude for chat on sensitive machines.
  • Accepted risk: the session cookie is visible to other servers on 127.0.0.1. Same-user local processes are inside the trust boundary, since they could read the SQLite file directly.

Re-review: the same reviewer confirmed all 8 fixes RESOLVED and found 2 new low-severity issues. A stale job-handle race between cancel and close is fixed: close and terminate now run under one lock. A short window after launch, before the process joins its Job Object, is documented; taskkill /T and EFFECT_UNKNOWN cover it. Also noted as low: quoted secrets containing spaces aren't redacted, and an env/apiKeyHelper in Claude's own settings.json would bypass env stripping (auth status is the guard).

Round 3 (paid route + redesign): no way to leak the key and no XSS/CSRF regressions found. Fixed: input reservation bounded by UTF-8 bytes with a 400 KB cap, and overshoot flagged; streaming redaction over whole spans; the thread never dies holding a reservation; non-object stream events ignored; the test override refuses real keys; owner Resolve action for unresolved exposure. Accepted: chat bills the mission envelope only while the owner's auto-expiring development permit is on, as its copy states.

Round 4: paid cross-family review. Fixed: stdin/stdout deadlock outside the timeout; supervisor exceptions leaving tasks stuck; second server instance reconciling live tasks (data-dir lock); crash windows between ledger and task state (settle-first ordering plus orphan sweep); uncertain writers now block until the owner resolves the repair; Codex API cancel/deadline now returns promptly on Windows (worker-thread client); bounded chunked output reading; contained probe subprocesses; junction-safe, truncation-aware change snapshots; temp sandbox cleanup; env-proxy bypass in the fetcher; credential-dir descendants rejected as roots; multiline secret redaction; credential URLs sanitized; backup name collisions and missing task logs; atomic attachment writes; durable chat dispatch; atomic memory corrections; session cookie no longer sufficient (origin key in the URL fragment plus sessionStorage, X-Aesop-Key on every call); and 30 frontend/visual issues (stale async renders, duplicate submits, polling failures, focus loss, labels, mobile layout). Partly addressed: security-01, true OS sandboxing of provider CLIs. The scope text is now honest and agent tasks require a per-project acknowledgement.
