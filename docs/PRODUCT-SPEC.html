2. One indispensable user journey

  1. Launch the local application by established Windows launcher; only connect on loopback and use a fresh, validated login session.
  2. Open a selected permissible project folder and its persisted files, conversations, plans, notes and evidence.
  3. Discover and verify the intended provider lane. Show route type, actual access, quota/billing status (including per-model overlay where applicable), tool capabilities, permissions and last verified time. Mark UNKNOWN when untested.
  4. Attach files and content only with per-project, per-provider authorization. Show the exact context before sending; never switch provider silently.
  5. Chat, run one bounded agent task, or (when both lanes are free) dual-run in Arena. The actual writer, allowed paths, authorized tools, progress evidence, actual output and cancellation must be visible.
  6. Inspect files/diffs, preview, logs, research citations and operational expenses. Never show fabricated "running", simulated live messages or invented acceptance.
  7. Save result and source links. Restart and resume with the project in the same supported state; unresolved external effects remain explicitly unknown.

Success: The user completes a recurring real project workflow with less context re-entry, fewer unnecessary app switches, reliable evidence and recoverable errors—not simply a prettier dashboard.

6. Roundtable, War Room and Arena

Shipped Roundtable: Planning without contacting providers; owner-confirmed 2–4 speaker side-by-side compare; moderated live broker behind Evidence → Spend controls → Live roundtables (forced off at restart). Do not claim every discussed lane can speak simultaneously; Verify is mandatory.

Shipped Arena: In-app dual-lane comparison with estimates and free-route Run both (see §4). Arena is separate from Roundtable/War Room.

Desired (Roundtable expansion): 4+ eligible conversational providers with capability-based selection, structured openings, moderated rebuttals, evidence-backed dissent, time/spend ceilings and exportable transcripts. Candidates may include Codex, Claude, Cursor, Antigravity/Gemini, Grok, Z.ai and other verified lanes—not Copilot (retired). Specialist research connectors remain evidence inputs unless supported as speakers.

Admin War Room (shipped shell / Desired authority discipline): small coordination experience for authorized Codex/Claude/Cursor participants without inventing new merger or provider authority. Model-generated resolutions stay advisory until deterministic policy/owner workflow permits action. Keep Roundtable chat separate from write-capable agent tasks.

7. Agent control, source provenance and recovery

Shipped: Mutation-capable tasks need specific project/path, allowed operations, admission/worker owner, expected deliverable, test contract, cost/time bounds, honest progress and safe cancellation. Preserve changed paths, task receipts and source evidence. On stop/crash, reconcile into INTERRUPTED or EFFECT_UNKNOWN; never blindly replay. Foreman repair packet exports remain exports until an authorized team issues a repair order.

Shipped: Distinguish canonical decisions and user facts from derived memory. New derived content must be evidence-linked and explicitly accepted/promoted; corrections supersede prior interpretation with provenance retained.

11. Non-goals, authority and go/no-go

Current vision excludes music, general media generation/editing, model training, placeholder workspaces and public hosting. Studio is not intended to reproduce all features of Msty, Open WebUI or LibreChat. Copilot is not a Studio lane.

Go: dependable owner workflow that materially improves context continuity, execution control and time to accomplish project work. Revise: polished appearance but extra steps, high latency, repeated failures, spend ambiguity or unsafe permissions. Hold: inability to preserve control and data boundaries.

Governance (current): Roles (owner, 2026-11-11): OpenAI Director, Claude Orchestrator, Cursor Foreman, local LLM Warden—see CONTRIBUTING.md. Light path: writer worktree → full suite + needed live checks → PR → independent non-author exact-head review → merge. main is protected (green CI + review). Whoever finds a defect fixes it. This file does not authorize new expenses, credentials, host access or policy changes. All documentation added publicly must be publication-safe.

Research references: Msty; Open WebUI; LibreChat; repo README, AGENTS.md, vision, arena-compare. Before each major investment, refresh competitor capability and market velocity assumptions, compare build versus reuse and establish a concrete go/no-go metric.
